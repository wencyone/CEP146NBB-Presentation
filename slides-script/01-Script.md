## Slide 1 — *JavaScript*

**Script:**  

Let's start with JavaScript which was created in 1995. It was originally designed to make websites interactive, but today it's used for much more than that.

62% of developers said they use JavaScript often in the 2026 Stack Overflow survey, making it the most used language in the survey.

Unlike Python, JavaScript is mainly used to make websites interactive directly in web browsers. It also supports back-end development using Node.js, as well as mobile and desktop applications.
